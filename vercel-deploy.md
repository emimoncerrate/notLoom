# Deploy to Vercel (Recommended)

## Quick Setup:
1. Push your code to GitHub
2. Go to vercel.com
3. Click "Import Git Repository"
4. Select your repo
5. Click Deploy

## Custom Domain:
- Free: `your-app.vercel.app`
- Custom: `pursuit-demos.com` (if you buy domain)

## Environment Variables:
- Add your Firebase config in Vercel dashboard
- Google Drive API keys
- Any other secrets

## Benefits:
- ✅ Automatic deployments on git push
- ✅ Free tier (perfect for cohort)
- ✅ Global CDN
- ✅ HTTPS by default
- ✅ Preview deployments for testing
